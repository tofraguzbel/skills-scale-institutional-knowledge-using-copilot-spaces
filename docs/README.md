# OctoAcme Project Management Docs

This README provides a quick overview of the project management process used by OctoAcme and links to the supporting process documents in `docs/`.

## Project management process summary

OctoAcme uses a lightweight, cross-functional project lifecycle that begins with initiation, moves into planning, executes in iterative delivery cycles, and closes with release and retrospective activities. The process emphasizes customer value, clear ownership, risk management, communication, and measurable outcomes.
